# Internationalization (`src/i18n/`)

The web UI ships in two languages, **en** and **ru**, with no i18n library — typed dictionaries plus a React context.

## How it works

- `src/types/language.ts` — `Language = "en" | "ru"`.
- The choice is stored in IndexedDB (`settings` store, key `language` — [history-storage.md](history-storage.md)) via `src/db/get-language.ts` / `save-language.ts`.
- `use-language-state` loads it before the first paint (`App` renders `null` until the read resolves) and keeps `document.documentElement.lang` in sync. When no language is stored, the app renders in English and `LanguagePickerModal` (two buttons, English / Русский) asks once; the choice is saved. It can be changed any time in the first card of the Settings page.
- `App` provides `LanguageContext` (`{ lang, t, setLanguage }`); everything below it (`AppContent`, all pages) reads strings via the `useT()` hook. Hooks that produce user-visible text (`use-fit-processing` errors, `use-activity-summary` labels/dates) also call `useT()`.

## Dictionaries

- One namespace per file, one exported const per file (repo rule): `src/i18n/en/{common,nav,language,sidebar,dashboard,metric-help,charts,history,settings,power-settings,errors}.ts` and `help.tsx` (rich JSX content — the whole Help page bodies live in the dictionary; the `help/` components just render `t.help.*`).
- `src/i18n/en.ts` / `ru.ts` compose the namespaces into `EN` / `RU`; `translation.ts` derives `Translation = typeof EN`, so `ru.ts` fails to typecheck whenever a key is missing — that is the safety net when adding strings.
- `dictionaries.ts` maps `Language` → dictionary.
- Values are strings, arrays, `ReactNode` (help), or functions for interpolation (`t.errors.rideNotFound(id)`, `t.dashboard.processing(name)`).
- `t.locale` (`en-US` / `ru-RU`) feeds every `toLocale*` date call; `t.common.units` holds unit labels (km → км etc.) used by charts, tiles and the `formatDistance`/`formatSpeed` unit parameters.

## Adding a string / a language

- New string: add the key to the matching `en/` namespace, use it via `useT()`, then add the ru value — TS will point at the missing key.
- New language: extend the `Language` union, add a namespace directory + composer typed as `Translation`, register it in `dictionaries.ts`, add a button in `LanguagePickerModal` and the Settings language card.

## Deliberately not translated

`index.html` (title/meta/OG — SEO stays English; `<html lang>` is set at runtime), CLI/`lib` console output, raw FIT field names in the Raw File Data card, the "ReFit" brand, and `CyclistScene` labels (the scene is `aria-hidden`). `docs/*.md` stay English — `src/i18n/ru/*` is the only Russian text in the repo.
